# 🧮 Calculadora Simples - React JS

Projeto desenvolvido em **React JS** como atividade prática para criação de uma calculadora simples.

## 📌 Funcionalidades

A calculadora permite:

* Digitar o primeiro número;
* Digitar o segundo número;
* Escolher uma operação;
* Calcular o resultado;
* Limpar os campos.

### Operações disponíveis

* `+` Adição
* `-` Subtração
* `*` Multiplicação
* `/` Divisão

## ▶️ Como executar

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Depois, acesse o endereço informado pelo Vite no navegador.
